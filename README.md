# 👨‍👩‍👧‍👦 우리가족 VOCA (MYFAMVOCA)

온 가족(아빠 · 엄마 · 은봉이 · 지봉이) 맞춤형 영어 단어 학습 웹앱입니다.  
**엑셀 파일(`family_voca.xlsx`)만 수정해서 올리면**, 자동으로 최신 단어장이 생성되어 가족들의 휴대폰에 반영됩니다!

---

## 🚀 최초 1회 필수 설정 (GitHub Pages 활성화)

웹앱을 가족들이 접속할 수 있도록 GitHub 저장소 설정을 1회만 변경해 주셔야 합니다.

1. 저장소 상단의 **`Settings` (⚙️ 톱니바퀴 아이콘)** 탭을 클릭합니다.
2. 왼쪽 사이드바 메뉴에서 **`Pages`** 를 클릭합니다.
3. 가운데 **`Build and deployment`** 섹션의 **`Source`** 드롭다운 메뉴를 찾습니다.
4. 기본값인 `Deploy from a branch`를 클릭하여 **`GitHub Actions`** 로 변경합니다.
5. 설정이 완료되면 잠시 후 배포가 완료되며 상단에 접속 주소(`https://hits915-design.github.io/MYFAMVOCA/`)가 표시됩니다.

---

## 📝 단어 추가 및 수정 방법

단어의 모든 원본은 **`family_voca.xlsx`** 파일 하나입니다. 편한 방법(A 또는 B)을 선택해 수정하세요.

### 방법 A: GitHub 웹사이트에서 직접 올리기 (가장 쉬움)
1. 컴퓨터에서 `family_voca.xlsx` 파일을 엑셀 프로그램으로 열고 단어를 수정/추가한 뒤 **저장**합니다.
2. GitHub 저장소 페이지(`MYFAMVOCA`)로 들어옵니다.
3. 오른쪽 상단의 **`Add file`** 버튼을 누르고 **`Upload files`** 를 클릭합니다.
4. 방금 저장한 `family_voca.xlsx` 파일을 드래그하여 올리거나 파일 선택 창으로 선택합니다.
5. 화면 아래의 초록색 **`Commit changes`** 버튼을 누릅니다.
6. **약 1~2분 뒤** 자동으로 새 단어장이 완성되어 가족들의 폰에 반영됩니다!

### 방법 B: VS Code에서 커밋 & 푸시하기
1. VS Code 탐색기에서 `family_voca.xlsx`를 수정하고 저장합니다.
2. 왼쪽 소스 제어(Git) 탭에서 변경된 `family_voca.xlsx`를 스테이징(+)합니다.
3. 커밋 메시지(예: `단어 추가`)를 입력하고 **`Commit & Push`** 를 누릅니다.

## 📱 가족 휴대폰에서 사용 및 홈 화면 추가 방법

앱 주소: **`https://hits915-design.github.io/MYFAMVOCA/`**

### 🍏 아이폰 (Safari)
1. **Safari 브라우저**로 위 주소에 접속합니다.
2. 화면 하단 가운데의 **`공유` 아이콘** (네모 위로 화살표 모양: ⎋)을 누릅니다.
3. 메뉴를 아래로 스크롤하여 **`홈 화면에 추가`** 를 누릅니다.
4. 우측 상단의 **`추가`** 를 누르면 홈 화면에 예쁜 단어장 앱 아이콘이 생깁니다!

### 🤖 갤럭시 / 안드로이드 (Chrome)
1. **Chrome 브라우저**로 위 주소에 접속합니다.
2. 화면 우측 상단의 **`더보기 (점 3개 ⋮)`** 메뉴를 누릅니다.
3. **`홈 화면에 추가`** 또는 **`앱 설치`** 를 누릅니다.
4. 팝업창에서 **`설치`** 를 누르면 홈 화면에 앱이 추가됩니다.

## ⚠️ 엑셀 작성 규칙 및 자주 하는 실수

잘못된 내용이 들어가면 앱이 오류를 일으키는 것을 막기 위해, 시스템이 엑셀을 꼼꼼하게 검사합니다. 아래 5가지만 주의해 주세요!

1. **단어 칸에 작은따옴표(') 넣지 않기**
   - ❌ 잘못된 예: `don't`, `it's`, `let's`
   - ⭕ 올바른 예: `do not`, `it is`, `let us` 또는 기본형 단어로 적어주세요.
2. **예문 안에 해당 단어가 반드시 포함되어야 함**
   - 퀴즈에서 단어 자리를 가리고 빈칸 문제를 내기 때문입니다.
   - ❌ 잘못된 예: 단어 `negotiate` / 예문 `We talked about the contract.` (단어가 없음)
   - ⭕ 올바른 예: 단어 `negotiate` / 예문 `We need to negotiate the contract terms.`
3. **같은 시트 안에 똑같은 단어 중복 금지**
   - 이미 있는 단어를 다시 추가하지 않도록 주의하세요.
4. **난이도는 `Lv1` ~ `Lv5` 중 하나로 입력**
   - ❌ `1`, `Level1`, `상`, `초급`
   - ⭕ `Lv1`, `Lv2`, `Lv3`, `Lv4`, `Lv5`
5. **시트 이름 변경 금지**
   - 시트 이름은 반드시 **`아빠`**, **`엄마`**, **`은봉이`**, **`지봉이`** 4개여야 합니다.

## 🔍 빌드가 실패했을 때 오류 확인하는 방법

엑셀에 오타나 누락이 있어 배포가 되지 않는 경우, 어디가 잘못되었는지 한국어로 친절하게 알려줍니다.

1. GitHub 저장소 상단의 **`Actions`** 탭을 클릭합니다.
2. 가장 위에 있는 목록에 **빨간색 ❌ 표시**가 있다면 빌드가 멈춘 것입니다.
   *(오류가 나도 가족들의 기존 사이트는 안전하게 정상 작동합니다.)*
3. 해당 실패한 작업(빨간색 제목)을 클릭합니다.
4. 왼쪽 목록에서 **`build-and-deploy`** 를 클릭합니다.
5. **`4. 엑셀 검증 및 PWA 빌드`** 항목을 클릭해 펼칩니다.
6. 빨간 글씨 아래에 예를 들어 다음과 같이 문제 위치가 정확히 나옵니다:
   ```text
   ❌ [엑셀 검증 실패] 다음 오류를 수정한 후 다시 시도해 주세요:
    • [엄마] 18행: 단어 'passport'가 시트 내에서 중복되었습니다.
    • [아빠] 21행: 단어 'agree'가 예문에 포함되어 있지 않습니다.
   ```
7. 엑셀에서 해당 행을 고쳐서 다시 올려주시면 정상 배포됩니다!

│   ├── manifest.json         ← 앱 설치 정보(이름, 테마 색상 등)
│   ├── sw.js                 ← 서비스 워커 (오프라인 지원 및 캐시 갱신)
│   └── assets/               ← 앱 아이콘 이미지
├── .github/workflows/
│   └── deploy.yml            ← 엑셀 수정 시 GitHub Pages에 자동 배포하는 규칙
├── .gitignore                ← 임시 빌드 파일(dist 등) 제외 목록
